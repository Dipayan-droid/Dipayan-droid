Real-time smoke & fire detection using an IoT + AI pipeline. Trained an ensemble of XGBoost, LightGBM, and a PyTorch MLP on the Smoke Detection IoT dataset using dual T4 GPUs on Kaggle. Integrated with an Arduino + MQ-2 sensor with deviation-based auto-calibration and a live web dashboard.
